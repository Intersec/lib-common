Generate the WSDL corresponding to an IOP module.

\param[out] sb Output buffer. \param[in] iop_env_ctx The current IOP environment. \param[in] mod IOP module description. \param[in] impl Optional RPC set if you do not want to export the whole module. \param[in] ns WSDL namespace. \param[in] addr WSDL address location. \param[in] with_auth Add SOAP authentication headers. \param[in] with_enums Dump enums literal representations in WSDL.
