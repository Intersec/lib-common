Expand description

Convert a string to its integer value using an IOP enum mapping.

This function will return err if the string value doesn’t exist in the enum set.

Prefer the macro version iop_enum_from_str() instead of this low-level API.

\param[in] ed The IOP enum definition (__e). \param[in] s String value to look for. \param[in] len String length (or -1 if unknown). \param[in] err Value to return in case of conversion error.
