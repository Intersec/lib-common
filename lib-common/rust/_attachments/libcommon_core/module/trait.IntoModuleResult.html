Expand description

Trait for converting a callback return value into a module’s result type.

Implemented for () (infallible) and Result<(), E> where E: Into<Box<dyn Error>>. This allows the initialize and shutdown callbacks to return either nothing (when they cannot fail) or any Result<(), E> without forcing the caller to box the error themselves.
