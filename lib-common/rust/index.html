API documentation of the crates

Along with C, Rust is the other compiled language supported in lib-common. The API documentation above is generated by rustdoc, and is refreshed each time this website is built.

Rust code of lib-common

The Rust code of lib-common lives in the rust/ directory of the repository. It is not a rewrite of the C code but a wrapper around it: the C symbols are exported to Rust with bindgen, and exposed in the bindings module of the crates that need them. As a consequence, most crates provide both a Rust API and the raw bindings of their C counterpart.

Build system

waf remains the main build system: it schedules the build and calls cargo for the packages producing artifacts used by the C code (staticlib, cdylib and bin), while the packages producing only Rust libraries are entirely handled by cargo. All the packages belong to a single Cargo workspace, shared with the projects based on lib-common, and are listed in the members field of its Cargo.toml.

Because the Rust code wraps the C one, the API documentation can only be generated after the C libraries have been built:

waf configure
waf
cargo doc --workspace --no-deps
